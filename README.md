# planets-code-of-conduct
This repository is maintaining a code of conduct, how to deal with border and peace agreemtns when playing on planets.nu

# Intention of this document
The intention of this code of conduct is, to shorten ingame negotiation. A player can simply refer to this code of conduct, and safe time for negotiating all terms and conditions again and again during his games.
A player committing to this code of conduct committs to the rules mentioned below.

# Defined Terms

## Border agreement

A border agreement is a line or a set of combined lines, that uniquely delimits 2 players territories.

## Non Agression Pact (NAP)

This is an agreement between 2 players defining peaceful coexistance.

# Rules for a border agreement

The following default rules apply to a border agreement:

1. The agreement is valid until the end of the game, unless an other duration is explicitely defined.
2. Cancellation of a border agreement
   - An agreement can be cancelled by ingame message for the next turn, unless defined differently.
   - This means if a player cancels the agreement while giving orders in turn X, already in host run for turn X+1 he can break the former border agreement rules without breaking the conditions of this code of conduct.
   - In case a cancellation period is defined any breach of the agreement allows immediate cancellation of the agreement.
   - any cancellation has to be done as a written ingame message clearly mentioning the term "cancelation of border agreement"
4. No cloaked or uncloaked ships may pass a defined border under a border agreement, unless mutually agreed.
   - This includes HYP movements.
   - This does not include Firecloud movements.
   - This does not include wormhole movements.
5. No mine fields exceed the agreed border during the border agreement. This explicitely includes Privateer hidden minefields.
6. A border agreement is an agreement between 2 players. It does not define anything for 3rd party player behaivior. 3rd party player movements do therefore not break the border agreement. 

# Rules for NAP

The following rules apply for a NAP

1. A NAP is an agreement between 2 players defining peaceful coexistance.
2. The agreement is valid until the end of the game, unless an other duration is explicitely defined.
3. A NAP does not imply a border agreement. But it is recommended to agree on a border agreement together with a NAP.
4. A NAP is valid without the ingame diplomacy setting "safe passage".
   - It is recommended to wing a NAP with a diplomacy setting "safe passage", to avoid actions, that are seen as a breach of the NAP.
   - Revoking "safe passage" i not seen as a cancelation of a NAP. A cabcellation has to be given explicitely as given below.
5. Cancellation of a NAP
   - A NAP can be cancelled by ingame message for the next turn, unless defined differently.
   - This means if a player cancels the NAP while giving orders in turn X, already in host run for turn X+1 he can break the former NAP ules without breaking the conditions of this code of conduct.
   - In case a cancellation period is defined any breach of the agreement allows immediate cancellation of the NAP.
   - any cancellation has to be done as a written ingame message clearly mentioning the term "cancelation of NAP"
6. A NAP implies no attack on any ship, planet or base from the other player.
   - This includes ground attack (GA)
   - This include Rebel ground attack (RGA)
   - This includes Pillage mission.
   - This includes Super Spy mission.
   - This includes Imperial assaukt.
   - This includes any Horwasp pod mission. (Though this is often a matter of negotiation, as a pod mission might have been started long before, and the target was in 3rd party player hands at that time)
8. No mine field behaivior is defined by a NAP. It is recommended to cover this with a border agreement.
